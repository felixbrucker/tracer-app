# Tracer Android Application

Tracer is a modern Android application for network diagnostics featuring:
- **Live MTR Traceroute**: Real-time continuous traceroute table with Sent/Recv/Loss%/Best/Worst/Avg/Last/StDev statistics (WinMTR style).
- **Regular Traceroute**: Hop-by-hop visual timeline and response latency visualization.
- **Ping**: Real-time ping graph and summary statistics.
- **Favorites**: Fast target bookmarking and quick launch.
- **Settings**: Customizable traceroute and ping default parameters.
